# M10 — Documentación y evidencia

**Alcance:** README operativo, ADR, modelo, API, mediciones, ataque, trazabilidad y checklist.  
**Requisitos:** secciones 9–12, REQ-B1-01/04 y todos los artefactos exigidos.  
**Dependencias:** todos los módulos, pero puede iniciarse con plantillas.

**Tareas:** mantener un ADR por decisión; documentar alternativas; publicar endpoints/códigos/errores; actualizar modelo y matriz con cada cambio; registrar ataques fallidos y confirmados.  
**Aceptación:** otra persona puede levantar, probar y explicar el sistema sin conocimiento previo ni internet; no quedan plantillas presentadas como evidencia final.  
**Tests:** revisión documental y ejecución literal de comandos documentados.
